2. Strict Prohibition on Keystroke Logging (No Keylogging)

100% On-Device Input

The core principle of FlexKey Keyboard is absolute input isolation:

  • No Keystroke Capture: We declare and guarantee that FlexKey Keyboard NEVER captures, logs, records, saves, or transmits typed text to any external server or third party.
  • Passwords & Payment Data: Passwords, PIN codes, bank card numbers, and CVC/CVV security codes are NEVER logged or saved.
  • Local Processing: Autocorrect algorithms, next-word predictions, and text suggestions operate strictly on-device in isolated Volatile RAM.

3. Explanation of Android System IME Warning

Android OS Reference

When enabling FlexKey Keyboard in Android System Settings, Android displays a standard warning:

"This input method may be able to collect all the text you type, including personal data like passwords and credit card numbers..."

This is a standard system warning displayed by Android for ALL third-party Input Method Editors (IMEs). It is generated automatically by Android regardless of whether the keyboard actually collects data or not. We confirm that FlexKey Keyboard does NOT misuse system IME capabilities to intercept or transmit any user text.

4. Data Processed & Transmitted by the App

Google Play Data Safety

FlexKey Keyboard processes data to provide keyboard features, display rewarded ads, and maintain app security. Here is the full disclosure of data processing:

A. Local On-Device Storage (App Sandbox)

  • App Preferences: Key heights, selected color theme, sound and vibration intensity settings are saved locally in private App Sandbox (SharedPreferences/Room).
  • User Dictionary: Words you manually add or learn locally are stored in a private database on your device and can be cleared anytime in App Settings.
  • Clipboard History: Snippets copied to clipboard are stored in local temporary RAM for easy pasting and can be cleared in one click.

B. Network Data Transmission (Third-Party SDKs)

  • Yandex Mobile Ads SDK (Rewarded Ads): Processes Advertising ID (AAID), IP address, device specs (model, OS version), and ad interaction telemetry for rewarded video ads (e.g. unlocking custom themes).
  • Klipy GIF API (api.klipy.com): Transmits user search queries entered into the GIF search bar to fetch GIFs/stickers, alongside standard HTTP request IP address.
  • Firebase App Check / reCAPTCHA: Transmits device hardware signals and IP address to Google servers to verify app authenticity and prevent fraud.
  • Dictionary Downloads: Downloads offline language packs via HTTPS from GitHub.

Информация об обработке данных приложения FlexKey Keyboard:

А. Локальное хранение на устройстве (App Sandbox)

  • Настройки: Высота клавиш, выбранная тема, параметры звука и вибрации сохраняются локально в SharedPreferences/Room.

  • Yandex Mobile Ads SDK (Реклама за вознаграждение): Обрабатывает рекламный идентификатор (AAID), IP-адрес, технические характеристики устройства и телеметрию просмотров для разблокировки премиум-тем.

  • Firebase App Check / reCAPTCHA: Передаёт аппаратные сигналы устройства и IP-адрес на серверы Google для защиты приложения от мошенничества и взлома.
  • Загрузка словарей: Загружает языковые пакеты по HTTPS с GitHub.
